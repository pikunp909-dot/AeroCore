# AeroCore SDK

AeroCore is a high-performance, robust drop-in replacement for expired UJJWAL/MetaCore SDKs, featuring:
- 60-day offline license validation (Ed25519 signature verification)
- Clock-rollback defense via EncryptedSharedPreferences
- Native ShadowHook integration & Anti-Debug/Anti-Tamper protections
- Forked BlackBox virtual engine core
- Full MetaCore backward-compatibility shim
